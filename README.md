### Selected Work

**Core Systems**

- **[Surf](https://github.com/harihkk/surf-agentic-browser)** — An autonomous browser agent running on a three-tier LLM cascade, built around resilience, state, and recovery.
- **[AskRC](https://github.com/harihkk/AskRC)** — A production-style RAG pipeline for research computing documentation, with ingestion, orchestration, tracking, and validation.
- **[Prompt-Budd](https://github.com/harihkk/Prompt-Budd)** — A prompt tooling extension for scoring, rewriting, PII checks, and model-backed feedback inside the user workflow.
- **[GenBI](https://github.com/harihkk/GenBI)** — A natural-language analytics system that turns plain English into charts, tables, and structured answers.
